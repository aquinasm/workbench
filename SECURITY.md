# Security Policy

## Reporting a Vulnerability

Workbench manages local services, shell profiles, databases, and filesystem cleanup operations, so security issues are taken seriously.

If you discover a security vulnerability, please **do not** open a public GitHub issue. Instead, report it privately using GitHub Security Advisories (the **Report a vulnerability** button in the repository's **Security** tab).

When reporting, please include:

- A clear description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Affected platform(s) and version(s).
- Any suggested fix or mitigation, if you have one.

We will acknowledge your report as soon as possible and coordinate a fix before public disclosure.
